# Thomson 240G Google TV (<box-ip>): wijzigingen en terugdraaien

adb: `adb`, verbinden met `adb connect <box-ip>:5555`

Uitgangssituatie (2026-11-17): Android 14 (build URO4.260304.084), launcher `com.google.android.apps.tv.launcherx`, KPN-app 09.06.04, geen Kodi.
CEC: hdmi_cec_enabled=1, power_control_mode=broadcast, power_state_change_on_active_source_lost=standby_now, tv_wake_on_one_touch_play=1.

| Datum | Wijziging | Terugdraaien |
|---|---|---|
| 2026-11-17 | Projectivy Launcher (com.spocky.projengmenu) geïnstalleerd via Play Store; meldingstoegang en telemetrie geweigerd. HOME-rol op Projectivy gezet | `adb shell cmd role add-role-holder --user 0 android.app.role.HOME com.google.android.apps.tv.launcherx` en `adb shell pm uninstall com.spocky.projengmenu` |
| 2026-11-17 | Google TV-launcher kort uitgeschakeld (`pm disable-user`) om Projectivy standaard te maken: **mislukt**, het Google-herstelscherm (setupwraith RecoveryActivity) draaide dan in een lus. Direct teruggezet met `pm enable com.google.android.apps.tv.launcherx` en HOME-rol weer op launcherx. | Niet meer nodig |
| 2026-11-17 | **Test 4** (akkoord Joost): toegankelijkheidsservice van Projectivy aan: `settings put secure enabled_accessibility_services com.spocky.projengmenu/com.spocky.projengmenu.services.ProjectivyAccessibilityService` + `settings put secure accessibility_enabled 1` (stond eerst op null/0) | `adb shell settings delete secure enabled_accessibility_services` en `adb shell settings put secure accessibility_enabled 0` (en Projectivy desnoods `pm uninstall com.spocky.projengmenu`) |
| 2026-11-18 | **Ontwikkelstand** (op verzoek van Joost, zodat doorwerken kan als de TV uit is): `svc power stayon true` (scherm/box blijft wakker) en HDMI-CEC uit: `cmd hdmi_control cec_setting set hdmi_cec_enabled 0` (box negeert stand-by van de TV, en de TV wekt de box niet meer) | Terug naar normaal: `adb shell cmd hdmi_control cec_setting set hdmi_cec_enabled 1` en `adb shell svc power stayon false` |
| 2026-11-17 | Projectivy heeft permissie READ_TV_LISTINGS gekregen (die stond geweigerd door de onboarding): `pm grant com.spocky.projengmenu android.permission.READ_TV_LISTINGS`. Daarvoor moest Projectivy herstart worden; na force-stop moest de toegankelijkheidsservice opnieuw aan (zelfde `settings put secure enabled_accessibility_services …` als Test 4). | `adb shell pm revoke com.spocky.projengmenu android.permission.READ_TV_LISTINGS` |
| 2026-11-17 | Meldingstoegang van Projectivy, die Joost per ongeluk aanzette, weer ingetrokken: `cmd notification disallow_listener com.spocky.projengmenu/com.spocky.projengmenu.services.notification.NotificationListener`. Lijst staat nu weer als origineel (alleen launcherx). | Niet nodig (zet het liever niet aan) |
